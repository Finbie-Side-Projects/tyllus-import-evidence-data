# Publish a source-faithful CBP response worksheet

Simply Trade's 64-question episode, Carra Globe's ANPRM article and FreightFigures'
import disclosure guide ask importers to prepare evidence and cost information.
A blank response workbook can turn that reading into an organized evidence
exercise. This is an inferred use case, not a publisher request or acceptance.

Retain all 64 official questions and seven source sections, with PDF page links,
source provenance and blank owner/response/evidence/time/cost/assumption fields.
Keep official wording in English, make all questions readable without JavaScript,
and localize the surrounding interface in four languages. No invented answers,
compliance score, legal conclusions or automatic agency submission.

Validate extraction at heading and page boundaries; compare actual downloaded
CSV to committed source, test navigation and mobile layout, publish and inspect
the live site before completion. Offer the concrete live resource to a verified
relevant publisher only with the applicable sending approval.
