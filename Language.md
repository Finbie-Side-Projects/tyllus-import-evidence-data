# Language

English is the default interface; Turkish, Italian and Spanish interfaces use `/tr/`, `/it/` and `/es/`. All interface text, accessible labels, filter labels, topics and type names comes from `locales/*.json`. The root forwards to `/en/` while retaining complete English fallback content.

Official agency names, notice titles, abstracts, actions, docket IDs and taxonomy match terms stay in source English and are marked `lang="en"`; the interface explains this. Do not fabricate translations of legal source text. Dates use the active locale. Theme options are light and dark; system preference may determine the initial theme but is not a selectable option.
